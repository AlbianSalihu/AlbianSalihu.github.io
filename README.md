# Albian Salihu — Portfolio

Personal portfolio of Albian Salihu, Robotics Engineer based in Lausanne, Switzerland.

**Live site: [albiansalihu.github.io](https://albiansalihu.github.io)**

## Stack

- [Astro](https://astro.build/) — static site generator
- [Three.js](https://threejs.org/) — 3D particle background
- TypeScript, bilingual EN/FR

Built on the [astro-darkness](https://github.com/kpab/astro-darkness) template.

## Local development

```bash
npm install
npm run dev
```

## Build & deploy

Deployed automatically to GitHub Pages via GitHub Actions on push to `main` or `working`.

```bash
npm run build   # production build → dist/
npm run preview # preview the build locally
```
